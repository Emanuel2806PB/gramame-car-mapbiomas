# Apresentação do TCC em LaTeX

O arquivo `apresentacao.tex` utiliza XeLaTeX e o formato Beamer 16:9.

## Uso no Overleaf

1. Crie um projeto em branco ou uma pasta própria para a apresentação.
2. Envie `apresentacao.tex`.
3. Crie a pasta `figuras` e envie os quatro arquivos PNG fornecidos.
4. Em **Menu > Compiler**, selecione **XeLaTeX**.
5. Defina `apresentacao.tex` como documento principal e recompile.

O roteiro contém 16 slides e foi dimensionado para uma exposição aproximada de 15 a 18 minutos. O nome do orientador pode ser acrescentado à capa quando estiver definido.
